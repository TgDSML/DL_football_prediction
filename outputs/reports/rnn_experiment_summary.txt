RNN Experiment Summary
======================

All recurrent models in this table use manual from-scratch recurrent computation.
No experiment in this summary uses torch.nn.RNN, torch.nn.LSTM, or torch.nn.GRU.

| Experiment name | Sequence length | Input type | Model type | Class weighting | Test accuracy | Test macro F1 | Main observation |
| --- | ---: | --- | --- | --- | ---: | ---: | --- |
| home_only_seq5 | 5 | home history | single scratch RNN | none | 0.4788 | 0.3778 | Weakest context; useful baseline but misses away-team signal. |
| home_away_seq5 | 5 | concatenated home + away history | single scratch RNN | none | 0.5163 | 0.3984 | Adding away history gives a clear accuracy gain over home-only. |
| home_away_seq10 | 10 | concatenated home + away history | single scratch RNN | none | 0.5204 | 0.3938 | Best RNN accuracy so far; longer history helps accuracy but not macro F1. |

Best RNN By Accuracy
====================

home_away_seq10 remains the best RNN by accuracy:

- Test accuracy: 0.5204
- Test macro F1: 0.3938

Best RNN By Macro F1
====================

home_away_seq10_weighted is now the best RNN by macro F1:

- Test accuracy: 0.5022
- Test macro F1: 0.4452

Comparison Against Classical Fixture-Level Baseline
===================================================

The best fixture-level classical ML accuracy is random_forest at 0.5211, which is
slightly above the best RNN accuracy of 0.5204.

The best fixture-level classical ML macro F1 is logistic_regression at 0.4237.
The weighted single-stream scratch RNN improves on that macro F1 with 0.4452.

Architecture Observation
========================

Class weighting improved macro F1, especially for draws, but reduced accuracy.
Increasing the draw-specific multiplier beyond balanced weighting made the model
predict more draws and reduced overall accuracy.

The dual-encoder architecture did not improve accuracy over the single-stream
home-away seq10 model. Its best macro F1, 0.4350, is useful but still below the
single-stream balanced seq10 model at 0.4452.
