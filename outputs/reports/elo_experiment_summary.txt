Elo Experiment Summary
======================

Implementation
==============

Elo ratings are computed in src/features/elo.py with:

- initial rating: 1500
- K factor: 20
- home win actual score: 1.0
- draw actual score: 0.5
- away win actual score: 0.0

For each fixture, the feature value is recorded before the match update. Post-match
ratings are used only for validation reporting and to carry ratings forward.

Answers
=======

1. Does Elo improve classical ML?

Yes for accuracy and log loss in the fixture-level comparison. XGBoost benefits
most by accuracy, improving from 0.5152 to 0.5243. Random Forest gains only
slightly in accuracy, but improves macro F1 from 0.4169 to 0.4232.

2. Does Elo improve RNN accuracy?

Slightly. The unweighted scratch RNN seq10 improves from 0.5204 to 0.5215.
The gain is small, but it sets a new recurrent accuracy result in this run.

3. Does Elo improve GRU macro F1?

No. The GRU seq50 h128 weighted macro F1 drops from 0.4549 to 0.4457.

4. Which model benefits most from Elo?

XGBoost benefits most among classical models by accuracy, with +0.0091. The
weighted scratch RNN benefits most by macro F1, with +0.0134 over its prior
weighted reference.

5. Is Elo more valuable than adding rolling sequence features?

For accuracy, Elo is more useful than the raw_plus_rolling sequence extension in
these runs. Raw_plus_rolling did not approach the best raw RNN accuracy, while
Elo slightly improved the raw seq10 RNN accuracy and improved fixture-level
XGBoost accuracy. For macro F1, raw_plus_rolling regularized GRU reached 0.4519,
while Elo weighted RNN reached 0.4586, so Elo also has the stronger current
macro-F1 result among these controlled additions.

6. Should Elo become a permanent feature?

Yes. Elo is leakage-free, cheap to compute, interpretable, and improves the
best fixture-level ML accuracy plus the weighted RNN macro F1. It should remain
as a permanent feature, while GRU-specific benefit should be revisited with
additional tuning.

Recommendation
==============

Keep Elo in the tabular and raw sequence feature builders. Treat it as a stable
long-term team-strength signal that complements short-term rolling form.
